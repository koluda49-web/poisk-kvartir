# Маршруты: 11 улучшений — дизайн

Дата: 13.09.2026. Заказчик — владелец сайта poisk-kvartir.onrender.com.
Основание: люди из ТикТока спрашивают в первую очередь маршруты, а не жильё.

## Что делаем и зачем

| # | Что | Где | Зачем |
|---|-----|-----|-------|
| 1 | Короткие ссылки на маршруты из видео: `/m/<slug>` и список `/m` | новые страницы | в комментариях отвечать ссылкой, в профиле ТикТока — одна ссылка на все |
| 2 | «По пути»: места до 5 км от дороги маршрута | `/marshrut`, `/m/…` | подсказать, что ещё посмотреть, не сворачивая |
| 3 | «Поделиться»: системное окно или меню (копировать, Telegram, Viber, WhatsApp) | `/marshrut`, `/m/…` | ссылку из адресной строки на телефоне не берут |
| 4 | Перетаскивание точек, ручной порядок | список на `/marshrut` и блок «Маршрут на день» на главной | порядок «к ближайшей» не всегда тот, что нужен |
| 5 | План дня (время выезда, сколько пробыть) + калькулятор топлива из трёх полей | `/marshrut` | понять, успеваешь ли, и сколько стоит дорога |
| 6 | Поездка на два дня с ночёвкой между днями | `/marshrut` | связать маршруты и жильё |
| 7 | «Сохранить картинкой»: PNG 1080×1920 с картой и списком | `/marshrut`, `/m/…` | пользоваться в дороге без связи |
| 8 | Форма «Предложить место» + страница проверки для владельца | подвал главной, `/predlozheniya?key=` | точки прибавляются без разработчика |
| 9 | Сезонные подборки `/podborka/<slug>` | новые страницы + полоска на вкладке мест | готовые темы для сайта и постов |
| 10 | «Чаще всего добавляют в маршрут» | вкладка мест + `/stats` | видно, о чём снимать |
| 11 | Будильник, чтобы Render не засыпал | сервер | GitHub Actions по расписанию срабатывает раз в 2–5 часов, а не раз в 10 минут |

## Решения

- **Всё в одном файле** `kvartiry-server.js`, как и весь сайт. Данные готовых маршрутов и подборок — JSON рядом (`маршруты-из-видео.json`, `подборки.json`), по образцу `маршруты.json`.
- **Порядок точек.** Режим `auto` (как сейчас, от первой к ближайшей) или `manual` (как расставил человек). Ручной режим включается перетаскиванием, выключается кнопкой «Упорядочить автоматически». Хранится в `localStorage.routeOrder`, в ссылке — `&o=1`. Готовые маршруты из видео всегда в ручном порядке.
- **Короткая ссылка остаётся чистой.** `/m/<slug>` показывает маршрут из видео, даже если у человека сохранён свой. Как только он что-то поменял — адрес становится обычным `/marshrut?p=…&o=1`, маршрут сохраняется как его собственный.
- **Картинка** рисуется в браузере на canvas из плиток OpenStreetMap (у них открытый CORS). Не загрузились за 6 секунд — рисуем без подложки, но с линией и точками.
- **Постоянные данные.** Диск Render бесплатного тарифа стирается при каждом выкладывании. Предложенные места и счётчики популярного пишем в `данные/<имя>.json` локально и, если в Render задан `GH_TOKEN`, коммитим этот файл в репозиторий через GitHub API с пометкой `[skip render]` (без перевыкладки). Без токена всё работает до перезапуска, а на `/stats` видно «постоянное хранилище выключено».
- **Будильник.** Если задан `RENDER_EXTERNAL_URL` (Render задаёт сам), сервер раз в 9 минут обращается к собственному `/ping` через внешний адрес. GitHub Actions остаётся запасным — будит после перезапуска.
- **Калькулятор топлива**: расстояние (подставляется из км по дорогам, можно поменять), расход л/100 км (по умолчанию 7,5), цена литра BYN (по умолчанию 2,60). Итог: литры и рубли. Расход и цена запоминаются.
- **Два дня.** Флажок «Разбить на два дня» (от 3 точек). Ночёвка по умолчанию после точки, где набирается половина пути; можно выбрать другую. Между днями — до 4 вариантов жилья рядом с последней точкой первого дня (`/api/places/stay`). В ссылке — `&d=N`.
- **Модерация.** Предложение попадает в список «новые»; владелец на `/predlozheniya?key=…` правит название, категорию, адрес, текст и нажимает «Добавить на сайт» или «Отклонить». Одобренные — группа «От читателей», id с 920001. Письмо-уведомление — тем же FormSubmit, что и «Оставить пожелание».
- **Популярное** считается по событию `route_add` с id точки, один посетитель — один голос за точку. Публичный блок показываем, только когда набралось хотя бы 4 точки с 2+ добавлениями.

## Ограничения (действуют на все задачи)

- Без флагов и политики; палитра сайта; ничего похожего на рекламу.
- Страница не должна тяжелеть на бесплатном тарифе: новые запросы кэшируются, тяжёлое — только по действию человека.
- Браузер владельца не трогать: никаких `taskkill /IM chrome.exe` или `node.exe`, процессы — только по PID.
- Проверки в браузере — по образцу `проверки/своя-точка.mjs`, у каждой свой порт, по одной за раз.

## Проверка

Каждая задача — своя проверка в `проверки/` плюс прогон существующих: `места`, `поездка`, `вкладки`, `возврат-и-фильтры`, `маршрут-на-карте`, `своя-точка`, `скрипт-страницы`, `страницы-и-выдача`.
