# План 04.10.2026 по разбору аналитики (Fable) — делает Opus

Источник: разбор Fable по Метрике/GSC/Вебмастеру (сырые данные — «Рабочий стол\ТикТок — Поиск квартир\Аналитика — сырые данные (04.10).txt»),
цифры Вордстата — «…\Вордстат — что ищут (29.09).txt» и «(02.10).txt» (дополнено 04.10).

Общие правила: названия только по Вордстату; title ≤ 60, description 120–160 (проверки/seo.mjs); ничего не выдумывать
(цены, вместимость — только из живых объявлений, «уточняйте у хозяина»); без флагов/политики/военных мемориалов;
клиентский JS в строках-шаблонах — без `${`, бэктиков и обратных слэшей; файл CRLF; локальный сервер с METRIKA_OFF=1
на своём порту (не 8080), гасить только по своему PID; %TEMP%\cdp-* не оставлять.

- На каждой странице города — блок «Ещё по городу»: -nedorogo, -odnokomnatnye, -usadby, -kottedzhi, районы Минска (-centr, -vokzal, …), /kvartiry-bez-posrednikov, /gde-ostanovitsya-*, /chto-posmotret-*, /doma-na-sutki-pod-minskom — только существующие и непустые (пустаяСтраница).
- На странице места (/mesto/*) — ссылки «Квартиры на сутки в <город>» и «Что посмотреть в <город>», если место в радиусе города-гида / рядом с городом со страницей.
