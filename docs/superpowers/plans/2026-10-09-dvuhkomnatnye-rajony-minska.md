## 2. Районы Минска по карте
Сейчас таблица районов Минска на /gde-ostanovitsya-minsk строится из поля района Kufar (196 объявлений), и Kufar, похоже,
ставит «Октябрьский» по умолчанию (105 из 196, от 20 BYN) — цифры врут. Сделать для Минска районы по координатам, как
для областных городов (РАЙОНЫ_ПО_КАРТЕ, коммит c6eb7a6), только объявления с точными координатами (без approx):
- Варианты: (а) административные районы Минска по полигонам OSM (admin_level=9? — проверь, есть ли в OSM границы районов
  Минска: Центральный, Советский, Первомайский, Партизанский, Заводской, Ленинский, Октябрьский, Московский, Фрунзенский) —
  предпочтительно, т.к. люди ищут «квартира на сутки минск заводской/фрунзенский/партизанский/октябрьский»;

- Таблица: те же правила (≥3 объявлений в районе, ≥3 района, до 9 строк для админ-районов), подпись честная + © OSM.
